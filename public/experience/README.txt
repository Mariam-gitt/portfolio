Put your company photos in this folder using EXACTLY these file names:

  fantech-desk.jpg
  pitb-building.jpg

Tips:
- On Windows, turn on "File name extensions" in File Explorer so you don't end up with names like fantech-desk.jpg.jpg.
- .png or .webp also work, but then update the `image` path in src/data/content.ts to match.
- If a file is missing, the site just shows the year instead of a broken image.
