Put your project screenshots in this folder using EXACTLY these file names:

  movie-explorer.png
  wordknit.png
  rag-chatbot.png
  ecommerce.png

Tips:
- Landscape screenshots (about 1600 x 1000) look best. Taller pages are cropped from the top.
- .png, .jpg or .webp all work. If you use another extension, update the `image` path in src/data/content.ts.
- Until a file exists, the site shows a "Screenshot coming soon" placeholder.
